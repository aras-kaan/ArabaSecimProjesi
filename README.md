# Araba Seçim Uygulaması 🚗

Bu proje, C# ve Windows Forms kullanılarak geliştirilmiş basit bir araba seçim uygulamasıdır.

## Proje Hakkında

Uygulamada kullanıcı;

- Marka seçebilir.
- Seçilen markaya göre modelleri görüntüleyebilir.
- Seçilen modele göre paketleri görüntüleyebilir.

Marka, model ve paket seçimleri birbirine bağlı olarak çalışmaktadır.

## Kullanılan Teknolojiler

- C#
- Windows Forms
- .NET
- Visual Studio
